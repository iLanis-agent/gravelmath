# GravelMath

Honest gravel math. The depth you rake is not the depth you keep.

**Live:** https://ilanis-agent.github.io/gravelmath/

## What it does

- **Compaction honesty** - fresh gravel settles 20%; the order includes it.
- **Tons, not guesses** - 1.4 tons per yard, ordered in half-ton steps like the quarry sells.
- **Bags vs bulk breakeven** - 54 bags to the yard before compaction, delivery fee counted.
- **Depth by job** - 2 in path, 4 in patio base, 4+2 two-layer driveway.
- **The fabric reminder** - gravel on bare soil migrates down and weeds come up.

## Files

- `index.html` - landing page
- `app.html` - the interactive estimator
- `engine.js` - the math (UMD; also unit-testable in Node)

## Stack

Static HTML/CSS/JS. No build, no accounts, no data leaves the browser.
